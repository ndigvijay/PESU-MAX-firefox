PESU-MAX is a tool that makes the best use of pesuacademy.

## Installation

### Firefox Extension

[Install PESU-MAX for Firefox](https://addons.mozilla.org/en-US/firefox/addon/pesu-max/)

### Local Installation

```bash
git clone https://github.com/ndigvijay/PESU-MAX-firefox.git
cd PESU-MAX-firefox/extension/
npm i
```

### Building the Extension

```bash
npm run build
```

Go to `about:debugging#/runtime/this-firefox`, select **Load Temporary Add-on**, and load `dist/manifest.json`.

## NOTE

Not an official package from PES University, made for only downloading resources quickly from PESU Academy.

All users data is stored locally in browser. NO proxy servers or External DB connected.

## FEATURES
- course content downloader *(across semesters,courses and units)*
- multi select course content types while downloading course materials
- Attendence calculator
- SGPA calculator
- CGPA calculator
- Faculty Information
- Previous Year Question Papers (PYQs)
